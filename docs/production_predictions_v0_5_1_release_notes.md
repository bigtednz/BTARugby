# BTA Rugby — Production Prediction Routing v0.5.1

## Summary

Production prediction routing was corrected so that `Gold_ModelDeploymentStatus`
is the source of truth for the active probability and margin champions.

This release is intentionally a plumbing/traceability change. With the current
deployment registry still pointing both targets at `EloOnlyBaseline v0.2.0`,
the numerical production output remains unchanged.

## Fixed

- Removed production-time re-registration of the default Elo champions.
- Production no longer changes `Gold_ModelDeploymentStatus`.
- Removed hard-coded use of `EloOnlyBaseline` when generating predictions.
- Probability and margin champions are resolved independently from the active
  deployment registry.
- Probability output is generated by the probability champion.
- Predicted margin is generated by the margin champion.
- If both targets use the same model/version, the calculation is reused.
- Unsupported or mismatched active model implementations fail closed instead
  of producing output under the wrong model label.
- Pipeline metadata records both active champion model/version values.
- Added `--show-predictions` for safe inspection of generated values during
  dry-runs.

## Regression test

Add `tests/test_production_champion_routing.py`.

The test suite covers:

1. Different probability and margin champions are routed separately.
2. When both targets share the same champion, one model calculation is reused.
3. An unsupported active champion fails closed rather than being silently
   mislabeled.

Run with:

```powershell
python -m unittest tests.test_production_champion_routing -v
```

If the repository is already standardised on pytest, the same unittest tests can
also be collected by pytest.

## Follow-up

The next modelling work should focus on genuinely new predictive information,
such as player/team-sheet strength and squad changes, rather than further
modifying the incumbent Elo mechanics without new evidence.
